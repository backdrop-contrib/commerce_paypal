# Commerce PayPal Checkout

## Introduction

Implements [PayPal Checkout](https://developer.paypal.com/docs/checkout/)
in Drupal Commerce checkout.

## Requirements

Requires at least jQuery 1.8, (See [using newer versions of jQuery](https://www.drupal.org/docs/7/theming/using-newer-versions-of-jquery)).

See also: https://www.drupal.org/project/commerce_paypal/issues/3053103.
